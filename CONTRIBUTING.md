# Contributing to jest-matcher-http

jest-matcher-http is a Jest extension with HTTP matchers, published to npm. See [README.md](README.md) for usage.

## Branches, Pushes and Releases

- **How changes reach `main`**: only through a branch and a pull request. Nobody commits to or pushes
  `main` directly.
- **What a push triggers**: every push to `main` runs the publish job, which publishes to npm and
  creates a GitHub release and tag whenever the pushed commits contain a releasable type.
  `.github/workflows/test_and_publish.yml` runs the tests (Node 20, 22, 24, Codecov) and CodeQL on every
  push and pull request to `main`; on a push to `main` its `publish` job then runs
  `npm run semantic-release` (semantic-release).
- **Commit types set the released version**: `feat` releases a minor version; `fix`, `perf` and
  `revert` a patch version; a `BREAKING CHANGE` footer a major version. Other types release nothing.

To change the repository:

1. Create a branch from `main`.
2. Commit on the branch and push the branch.
3. Open a pull request against `main`; it lands once the checks pass.

## Commit Messages

Commits follow [Conventional Commits](https://www.conventionalcommits.org/), enforced by commitlint
(`.commitlintrc.cjs`, extending `@commitlint/config-conventional`):

- Types: `feat`, `fix`, `docs`, `style`, `refactor`, `perf`, `test`, `build`, `ci`, `chore`, `revert`
- Header at most 100 characters, counting type, scope, subject, issue reference and any suffix such as
  ` [wip]`
- Body and footer lines at most 100 characters each
- Subject in lower case

### Check a Message Before Committing

Run in the repository root; it exits non-zero and names each broken rule:

```bash
printf '%s\n' "$MSG" | npx --no -- commitlint
```

## Git Hooks

Husky (`.husky/`) provides the hooks:

- `pre-commit`: validates the shared AI configuration with `npm --prefix ../ai-config run validate -- --repo jest-matcher-http`
  when a sibling `../ai-config` checkout exists, then runs `npm run lint && npm test`.
- `commit-msg`: runs commitlint on the message.
- `post-commit`, `post-merge`, `post-rewrite`, `pre-push`: generated by ai-config; they call
  `npm --prefix ../ai-config run git:hook` and never block.

## Tests

```bash
npm test                  # unit tests with coverage

```
